# Project summary — Olist E-Commerce Analytics

**One-line pitch:** End-to-end analysis of ~99K Brazilian marketplace orders using Python, MySQL, and Power BI to explain revenue, delivery risk, retention, and seller concentration.

## Problem
Marketplace revenue can grow while customer experience and seller balance weaken. This project measures those gaps.

## Approach
1. Clean and engineer features in Python (including Portuguese→English category translation).  
2. Store validated tables in MySQL.  
3. Build a 3-page Power BI dashboard (Overview, Delivery, Sellers).  

## Headline results
- ~R$13.6M revenue; AOV ~R$137  
- ~6.8% late deliveries; longer waits linked to worse review scores  
- ~3% repeat customers  
- Top sellers and São Paulo dominate marketplace activity  

## Recommendations
State/seller delivery scorecards · early late-order intervention · learn from top sellers · retention pilots for one-time buyers  

## Tools
Python (pandas) · MySQL · Power BI
